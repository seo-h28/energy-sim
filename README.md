# SunProof - 태양광 설계 시뮬레이터 (배포본)

옥상 태양광의 용량·비용에 따른 발전량, 회수기간, NPV를 계산하고 모든 가정과 수식을 화면에 공개하는 정적 웹 도구입니다.

- 이 저장소는 **배포용 빌드**(HTML·JS·데이터)만 담고 있습니다.
- 기본값 대부분은 출처를 확인하지 못한 **임의 가정**이며(화면의 `[Assumed]` 배지), 결과는 실제 설치 결과의 예측이 아닙니다. 실제 결정에는 전문가 견적이 필요합니다.
- 일사 자료: 기상청 ASOS(공공데이터포털), PVGIS(EU JRC), NASA POWER를 대조했습니다. 요금: 한국전력공사 요금표(2024-07-01 시행 값).
- 그래프: Chart.js v4.4.1 (MIT, `vendor/CHARTJS-LICENSE.txt`).
- 로컬 실행: 이 폴더에서 `python -m http.server 8000` 후 http://localhost:8000
